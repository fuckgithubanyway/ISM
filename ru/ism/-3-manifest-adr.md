# ISM Manifest: ADR

**Версия:** 0.7  
**Статус:** Нормативный

## Назначение

ADR защищает неочевидное решение от случайного изменения.

Формат:

```text
@ADR: <решение; причина>
```

ADR должен содержать причину. Если причина очевидна, ADR не нужен.

## Правила

- ADR допустим в Manifest, Meta и Semantic Spec.
- ADR запрещён в Exact Spec.
- ADR действует только из Definition.
- ADR не изменяет приоритет содержащего его правила и не может противоречить более высокому уровню.
- ISM-Agent не меняет защищённое решение без явно утверждённого изменения Definition.
- ADR в Projection не имеет нормативной силы и при Reconciliation является только кандидатом.

ADR размещается максимально близко к защищаемому решению и формулируется минимально.
